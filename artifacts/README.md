# Artifacts 归档说明

本目录用于保存可复核的验收证据、测试输入输出与历史归档；它不是运行时代码目录。

| 子目录 | 内容 | 使用方式 |
| --- | --- | --- |
| `e2e_data_skills/` | 数据分析 Skill / 知识库端到端验证使用的脚本、输入、事件记录和生成报告。 | 与 [验收报告](../docs/reports/data-skill-knowledge-e2e-validation.md) 对照使用。 |
| `ui_audit_2026-07-15/` | 历史 UI 审查工作区。 | 保留以便追溯，不作为当前 UI 实现基线。 |
| `legacy/database/` | 本地历史数据库备份。 | 仅用于需要时的人工恢复/核查；不得自动导入、覆盖现有数据库或提交到 Git。 |

新增验证产物时，请按“任务或验收主题 + 日期”建子目录，并保留必要的输入、脚本、输出和结论，避免将临时日志散落在项目根目录。
